2. INTERFACE CARREGA
   ├─> Painel de upload

   ├─> Seleciona arquivo .xlsx

4. PROCESSAMENTO NO BACKEND
   ├─> Validação do arquivo
   ├─> Leitura das abas
   ├─> Filtragem de equipamentos
   ├─> Cálculo de KPIs
   ├─> Identificação de padrões
   ├─> Geração de alertas
   └─> Deleção do arquivo

5. RELATÓRIO GERADO
   ├─> HTML profissional
   ├─> Inserido no painel
   └─> Pronto para visualizar/exportar

6. USUÁRIO VISUALIZA/EXPORTA
   ├─> Vê análise no navegador
   ├─> Imprime como PDF
   └─> Baixa como HTML

🟢 OK (verde) - Dentro da meta

================================================================================
🚀 COMO COMEÇAR
================================================================================

OPÇÃO 1: USAR LOCALMENTE (Agora!)
────────────────────────────────
1. cd projeto-analise-frota
2. python -m venv venv
3. venv\Scripts\activate (Windows) ou source venv/bin/activate (Mac/Linux)
4. pip install -r requirements.txt
5. python app.py
6. Abra http://localhost:5000

OPÇÃO 2: COLOCAR ONLINE (10 minutos)
─────────────────────────────────────
1. Crie conta GitHub (gratuita)
2. Crie repositório "projeto-analise-frota"
3. Faça upload dos arquivos
4. Crie conta Render (gratuita)
5. Conecte seu GitHub
6. Deploy automático!
7. Use em https://seu-projeto.onrender.com
